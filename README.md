# arimons/skills

개인용 + Vibe Coding 강의 배포용 AI 에이전트 스킬 모음.

[Agent Skills](https://github.com/vercel-labs/skills) 오픈 스탠다드를 따릅니다.

## 설치

```bash
npx skills add arimons/skills -g
```

## 스킬 목록

| 스킬 | 설명 |
|------|------|
| `context7-usage` | LLM API 코드 작성 시 Context7로 최신 문서 조회 강제 |
| `llm-model-reference` | Gemini/OpenAI/Claude 현행 모델 레퍼런스 (deprecated 방지) |
| `grill-me` | 프로젝트 설계 전 인터뷰로 막연한 아이디어를 구체적 설계로 변환 |

## 업데이트

```bash
npx skills update -g
```
