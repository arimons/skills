# Slide HTML to PPTX

슬라이드형 HTML을 PowerPoint 개체로 옮깁니다. 초안과 빠른 레이아웃은 HTML에서 잡고, 발표 직전 디테일은 PowerPoint에서 잡는 흐름을 위한 도구입니다.

## 쓰는 법

```bash
python3 scripts/html2pptx.py deck.html deck.pptx
python3 scripts/html2pptx.py deck.html deck.pptx --font "Pretendard" --font-bold "Pretendard"
```

`--font`를 주지 않으면 아리따 돋움으로 지정됩니다. 본문은 "Arita Dotum KR Medium", 굵은 글씨는 "Arita Dotum KR Bold"입니다. 이 서체는 굵기마다 서체 이름이 따로라서 bold 속성 대신 이름으로 구분합니다. 전사 PC에 자동 설치되므로 폰트 첨부도 필요 없습니다. 다른 서체로 내보낼 때만 `--font`를 지정하고, 굵기 서체가 따로 없으면 `--font-bold`에 같은 이름을 줍니다.

## 폰트 첨부

기본 서체인 아리따 돋움은 전사 PC에 자동 설치되므로 폰트를 첨부하지 않습니다. 질문도 하지 않습니다. Pretendard처럼 설치되지 않은 서체로 내보내서 다른 사람에게 보낼 때만, PowerPoint의 저장 옵션(파일 → 옵션 → 저장 → 파일에 글꼴 포함)을 켜라고 한 줄로 안내합니다. 이 옵션은 스크립트로 되지 않습니다.

## 전제

- 슬라이드 요소가 `position:absolute`나 고정 크기 grid로 배치되어 있을 것
- 캔버스가 1920×1080일 것 (1px = 1/144in로 환산됩니다)
- 스케일용 래퍼가 있다면 최상위 요소의 class가 `.page` 또는 `.slide`일 것

일반 웹페이지처럼 흐름 배치로 짜인 문서는 대상이 아닙니다.

## 변환 후

스크립트가 요소 수와 슬라이드 밖으로 나간 개체를 자동으로 점검하고 결과를 출력합니다. "자동 점검 통과"가 뜨면 그대로 넘기면 됩니다. 좌표를 그대로 옮기는 방식이라 부분적으로 어긋나는 일은 있어도 전체가 무너지지는 않으며, 어차피 PowerPoint에서 손으로 다듬을 파일입니다.

"확인 필요"가 뜰 때만 렌더링해서 눈으로 봅니다. `soffice --headless --convert-to pdf deck.pptx` 로 PDF를 뽑아 확인하십시오.

## 한계 — 미리 말해 둘 것

- **현재 스크립트는 단일 슬라이드만 변환합니다.** 첫 번째 `.page` 또는 `.slide`만 읽습니다. 여러 슬라이드가 들어 있는 HTML 덱은 슬라이드별로 분리하여 변환해야 합니다.

- **한 방향입니다.** PPT에서 고친 내용은 HTML로 돌아오지 않습니다. 변환 시점 이후로는 PPT가 원본이 됩니다.
- **줄바꿈이 고정됩니다.** 브라우저가 끊은 줄을 그대로 심고 PPT의 자동 줄바꿈을 끕니다. 그래서 폰트가 달라도 줄 모양이 유지되지만, PPT에서 문구를 늘리면 그 줄만 길어집니다. 문구 수정은 HTML에서 하고 다시 내보내는 편이 낫습니다.
- **그림자와 그라디언트는 옮기지 않습니다.** 얇은 선과 단색 면 위주의 문서를 전제합니다.
- **표는 PPT 표가 아니라 사각형과 텍스트 상자의 모음입니다.** 셀 단위 편집은 되지만 행 추가 같은 표 기능은 없습니다.

## 동작 원리

Playwright로 페이지를 띄워 각 요소의 좌표와 계산된 스타일을 읽습니다. 배경색이나 테두리가 있는 요소는 도형으로, 글자를 가진 요소는 텍스트 상자로 만듭니다. 한쪽 변에만 있는 테두리(카드 왼쪽 색 바 같은 것)는 얇은 사각형으로 따로 그립니다. 줄바꿈은 각 단어의 화면 좌표를 읽어 같은 줄에 있는 것끼리 묶는 방식으로 알아냅니다.
